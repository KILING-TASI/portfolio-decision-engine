## 声明协议再运行

```json
{
  "data":{"return_type":"total_return","source":"显式真实来源与口径","currency":"CNY","frequency":"daily"},
  "costs":0.0001,"seed":42,"initial_value":100000,
  "bootstrap":{"budget":0.25,"horizon":126,"paths":2000,"max_paths":4000,
    "block_lengths":[10,20,40,60],"rebalance_every":63,"mc_tolerance":0.01,"strict":true},
  "m2_walk_forward":{"min_train":2000,"train_steps":null,"validation_steps":0,
    "test_steps":126,"max_folds":20,"no_solution_policy":"cash"}

```

示例参数不是推荐配置。horizon必须等于test_steps，避免不同模拟期限和测试期限混比。max_folds限制算力但截断评价时明确evaluation_complete=false；路径数、最大路径、块长及容差也显式配置。小型教学命令用三折、每块100条路径，不代表研究精度或全区间验证。

只承接收益研究所需字段，拒绝migration、真实订单、因子、BL或事件等本批未支持配置，不能静默假装承接其行为。数据为明确共同币种与总回报；日/月频校验沿用已有接口。不补充事件/盈利预测爬虫，不自动把披露股票图变为风险序列。

## 每折

1. 训练窗口仅在测试开始前；估计协方差并生成风险导向候选、等权或受约束参考。
2. validation_steps=0时M2在同一训练样本上做条件MC收敛及固定块长敏感性校验，**不是独立验证样本**。设为至少30时，训练尾段作为单独风险校验样本，候选估计不使用该尾段。用途与起止均留档。
3. 在校验段执行完整drawdown_budget，所有预先声明块长均须满足规则，不事后挑测试表现好的块长。熊市覆盖默认仍要求2015/2018，否则记录insufficient_data，不放宽；教学或其他市场须显式声明不同覆盖规则。
4. 冻结选中权重，decision_as_of为回放决策截止而非真实历史文件冻结时间；拟合/校验CSV摘要与候选全部记录。真实源版本仍须另证。
5. 仅下一非重叠测试段计表现。下一折可以使用此前已发生的测试收益，不能回头改变已评价权重。

## 连续账户与无解

上一折的实际金额、权重漂移和现金带到下一折。自举初始持仓也使用此前账户权重，校验初始换仓费用而非每折假设从现金重新建仓。测试内按明确步数再平衡（不是交易所季度），与参考使用同一初始状态、费用、现金流和调仓时点。

无解/未收敛/覆盖不足保持各自状态和频数，不放宽预算。cash研究策略在折开始变为现金并计出售费用；previous_target保持上一目标策略，但不宣称通过新预算。初始无解时使用显式initial_weights或现金；不偷偷选择次优配置。参考不可行时记录现金替代并标记baseline_comparable_all_windows=false。

现金流须在评价区间，不能提供未建模的训练历史入金并称真实账户复盘。TWR/现金守恒沿用账本；自举未建模未来外部现金流，有现金流的预算观察不能当完全等价概率校准。

## 留档与评价

m2-evaluation.json schema=m2-walk-forward-v1；另有HTML、策略与参考连续账本/交易、输入字节、报告/方法摘要。每折保留选中频数、状态、完整候选、费用、换手、现金及测试回撤。只对有选中配置且测试长度等于模拟期限的窗口统计预算突破；末尾短窗口另列，不能混进命中率。状态拒绝与无解率分别记录。

首批验收：未来测试值改变不改变此前配置/校验摘要；分折连续账本与同一调仓序列的一次账户回测一致；无解现金变现只付一次费用；初始持仓MC与真实账本一致；所有固定块长参与筛选；短尾段与算力截断明确标记；对等参考使用同费用和资金规则。

## 真实资料闭环与未完成

先用明确教学序列证明因果切分与账本正确，真实输入只能在来源、事件/分红、汇率与版本可得性证据齐备后进入收益评价。当前实时取数成功不等于总回报成立；缺事件完整声明的真实净值应被拒绝，不能为完成样本外展示而改口径。

后续还需：有限真实总回报来源与原件/版本摘要核对、源级PIT资料认证、未来现金流的联合路径模拟、交易制度及基金确认、多重检验/独立外部样本、预算突破率不确定性。一次回放不能证明预算控制可靠，折间可能相关。首版明确降级，不认证全市场或未来亏损上限。
