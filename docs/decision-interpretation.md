# v0.7 决策解释与迁移优化

## 迁移可执行不等于达到目标

status=ok 仅表示求解及资金守恒通过。target_reached 要求资产加现金的最大权重差小于1e-6；max_target_gap 和 total_variation_target_gap 分别显示最大单项差和总体半L1差。不可行的一步到位方案不放宽约束。

禁止卖出的持仓金额 x_i 与目标权重 t_i 给出必要条件：迁移后总价值至少 x_i/t_i。相对当前资产+现金+已声明新增资金的额外金额下界按所有不可卖品种取最大值；目标为零且持仓为正则无有限的资金稀释方案。这个下界忽略成本和其他约束，不保证足够、不代表应投入资金。

原成本加L1目标可能存在多解。现在先解原LP，再在主目标值不超过最优值+max(1e-8,abs(最优值)×1e-9)的条件下，最小化资产和现金的平方金额偏离。变量按总金额归一化，降低币种单位对数值求解的影响。第二层求解未成功则保留原LP解并记录primary_only；不伪称使用了二级解。零费用的对冲买卖净额化，避免无意义的同时买卖。

新增risk_change用同一训练协方差比较当前、迁移后与目标年化波动，仅为历史参数估计。迁移后的回撤预算未重新校验，不将目标配置M2结果当作受约束账户的预算通过证明。

## 收益与风险取舍

decision_summary基于已有计算生成描述：是否有最终预算选择、与基准的年化收益差及回撤减少、迁移后偏离，以及Sharpe区间是否含零。不新增评分、买卖建议或统计显著性承诺。

“降低回撤，牺牲收益”与“收益和回撤均改善”分别显示；单次留出结果不说明长期优势。Sharpe自举区间含零说明当前样本证据有限，不证明未来没有收益。原始指标、内部状态和完整假设仍保留在JSON。
