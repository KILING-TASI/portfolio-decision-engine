## 首批新增：cn-fund-lookthrough 输入 v0.1 转换

参考仓库提交 `72bf3651269ef156f3f002641b224a968adbb3e0`。输入使用原始 positions/nodes/securities，不接受只剩汇总金额的分析输出冒充原始证据。

```sh
python -m portfolio_engine convert-lookthrough --input cn-input.json --out reports/converted-disclosure
python -m portfolio_engine verify reports/converted-disclosure
```

输出 source-input.json（原始字节）、lookthrough.json（本引擎原生输入）、conversion-result.json、report-manifest.json。将引擎配置的lookthrough_file显式指向生成的lookthrough.json，再运行已有run命令。路径相对于引擎配置目录，资料只进入supplemental，不进入M1/M2或M7数值计算。

| 上游字段 | 转换与保留 |
|---|---|
| asOf/currency | as_of/共同币种；不进行隐式FX转换 |
| positions id/node/weight | 保留root_positions，构建明确标注的账户包装节点；包装日期不是基金披露日期 |
| nodes reportDate/publishedAt/source/currency | 每节点disclosure_evidence与每条证券路径保留；来源可为上游明确文字依据，不凭空制造URL |
| disclosureScope/weightBasis及其他节点元数据 | 原样保留raw_metadata；缺少范围标not_declared，不能称全持仓 |
| securities kind/issuer/source | 完整security_metadata，证券键不改；路径保留issuer与mapping_source |
| holdings未满1、缺子基金、循环、身份缺失 | 保留未知比例与原因，不补现金、不重新归一化已披露股票 |

多根持仓可以指向同一基金，仍保留根持仓id；同节点内重复行只按相同证券/子基金键及类型相加，原行保留在快照中。AH证券即使指向同一发行人也不合并证券键。发行人映射依据只是输入声明，未自动独立认证。缺发行人映射的已知股票不丢弃，而记为unmapped_stock_issuer_weight；缺证券分类进入unknown。

源日期需reportDate≤publishedAt≤asOf；不能用报告期冒充当时已发布。首版最多100项根持仓、1000节点、每节点5000行、20层披露、100000次路径访问。账户包装层不消耗披露深度。毛额超过100%的杠杆节点拒绝，不截断；部分披露结果不外推全组合风险。

转换仅声明输入适配成功，不声明原文已解析、映射已核验或市场资料全覆盖。首批用明确教学输入与异常测试验收；真实报表提取由cn-fund-lookthrough对应任务完成后，使用其冻结、可定位输入复验。

## 接续批次：资料可用时点

原输入已检查reportDate≤publishedAt≤asOf，不重复制作另一套日期系统。补强两个接口：convert-lookthrough可显式传--as-of；组合run使用data.as_of（未提供则为收益末日）作为额外截止日，取它与穿透输入及转换请求截止日中的最早者，拒绝晚于该日的披露/版本可得日。不能用较晚的穿透文件绕过组合研究截止日；账户包装节点也不能把当前根权重伪称历史持仓。

上游节点可声明retrievedAt、availableAt、frozenAt、versionId、sourceSha256，转换到原生同名snake_case字段，并保留raw_metadata。持仓期、披露日、采集日和版本可得时点分别输出，缺采集时间显示未提供，转换时间不冒充采集时间。带时区时间戳按Asia/Shanghai日级截止解释，不承诺盘中可得性。

`convert-lookthrough --historical`或组合配置lookthrough_historical=true要求每个实际披露节点有来源版本号、64位来源摘要、可得时间及冻结时间；可得和冻结须不晚于研究截止日。缺这些证据拒绝历史模式，不能只凭所属日期或今天取到的修订历史声称当时版本。包装节点是结构元数据，不当作基金原文，只有实际披露节点要求冻结证据。非历史模式仍检查发布日期及明确的版本可得日，不生成PIT核验通过结论。

该门槛目前检查输入声明和日期关系，未读取/认证对应PDF原始字节，不能称已验证历史源真实性；hash不是签名。真实接入下一步验收需将sourceSha256与已留存原件/版本目录逐一核对，证明原件、版次、金额及时间，随后才能进入M2全流程样本外验证。已晚于截止日的更正/重述输入拒绝，不自动改取“看起来较早”的版本；调用者显式提交当时版本。

首批时点验收：组合截止日早于穿透披露则拒绝；采集日单列且不自动视为可得日；已明确可得日超限的修订版拒绝；历史模式缺冻结证据拒绝；两期股票差异仅展示结构，不能转成买卖记录或全组合事件风险。盈利预测和事件台账由主工作台/规则库提供，本引擎不新增爬虫。

## 首批验收

1. 联接+主动基金教学输入与上游固定版本的证券敞口、发行人敞口、已知/未知比例一致；已知+未知=1。
2. 缺证券、缺发行人、循环与缺子基金保留不同状态；两项根持仓投同一基金不被错误拒绝。
3. 原始输入字节、原披露期/发布日期/来源/币种、映射依据及未知原因可追溯；原始或方法变化核验有相应状态。
4. 季报十大或局部披露不归一到100%；未来披露、币种冲突和杠杆拒绝。
5. 转换报告明确只是披露结构，不能推导实际交易、全组合VaR、事件损失或实时暴露。

## 后续优先级

| 顺序 | 工作 | 门槛与缺口 |
|---|---|---|
| P1 | 有限管理人/版式的真实半年报、年报输入对接 | 先取得原表定位、单位/币种/金额/净资产口径、来源版本及金额勾稽；保留无法提取部分，不能承诺任意PDF |
| P2 | M2完整预算筛选的walk-forward | 每折只用当时可得收益与披露；候选生成、选择与测试隔离；冻结窗口/成本/参数/尝试数量；比较收益、预算突破与未收敛，避免将重叠预测当独立试验 |
| P3 | 披露结构与收益风险的对照 | 显示各自日期/口径及覆盖范围；部分股票穿透只能描述已知结构，不能直接推导全组合风险 |
| P4 | 风险事件观察与披露路径关联 | 接入主体/事件日期/版本/来源及发行人映射；只显示可证实关联与未知，不从关联比例算确定损失或给统一风险评分 |
| 后置 | PCF/IOPV/真实申赎成本 | 与既有同日收盘偏离区分；需成分篮子、现金替代、估值时间、份额、费用、资金/券源、申赎与成交限制，不称既有观察为可成交套利 |

旧收盘偏离观察沿用，首批没有新增套利模型或后台扫描。每一阶段独立验收，前一步数据或证据不足不能以新增指标掩盖。
