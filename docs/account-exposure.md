# 声明账户金额与披露支持的资产敞口（待审）

这是独立的离线研究视图：连接根基金、直持股票、普通债、转债及账户现金，使用显式金额、币种、估值日和披露时点。它不读取账户，不代表实时全量穿透，不产生交易指令；不使用未通过总回报准备的净值做 M2 正向验收。

## 一条命令生成报告

安装现有项目依赖后，在包含本批代码的分支执行：

```sh
python -m portfolio_engine account-exposure --input examples/account-exposure-demo.json --out reports/account-exposure
python -m portfolio_engine verify reports/account-exposure
```

打开 `reports/account-exposure/exposure-report.html`；同时保存 account-exposure.json、原始输入及方法/文件摘要。输出目录必须不存在，旧报告不覆盖。依赖顺序仍为 #1 → #2 → #3 → #4（MIT）→ 本批；公开发行仍是 v0.7.0，本功能尚未发行。

## 输入与计量

输入 `account-exposure-input-v1`，结果 `account-exposure-result-v1`，方法 `declared-account-exposure-v1`。基础金额单位和共同币种必须明确；全部根持仓使用相同估值日且不晚于资料截止，不隐式换汇或把“万元”猜成元。根持仓 position_id 与 economic_lot_id 均唯一，直持必须声明 origin=direct_account_lot。来自基金披露的派生行不能作为账户直持重复导入。

账户金额层与底层敞口是同一总额的两种描述，不能相加。同证券可以同时存在于基金和独立直持，真实的两条经济持仓路径各计一次后汇总；按名称或发行人删去重合会低估真实敞口。经济持仓身份和来源是输入声明，不能认证申报者是否重复提供了账户原件。

基金披露使用已有递归图检查，保留持仓期、发布/可得/采集声明、循环和缺披露。当前声明金额乘以旧期披露比例只是敞口估计，不是假设同日真实底层估值。缺证券身份/分类、缺子基金和未披露部分留在未知。证券、发行人、行业分别记录来源；发行人/行业缺失不会使已识别证券消失，也不会归入“其他”假装已知。没有单独映射依据的非空发行人/行业被拒绝。

现金 root.amount 是总账户现金，其中 frozen_amount 显式声明冻结部分；可用 = 总现金 - 冻结。基金披露现金属于间接资产敞口，不加入账户可用现金。两者不重复增加账户总额，证券分类缺失不改变现金状态声明的来源局限。

## 资产权重与风险分开

普通债只有在输入提供修正久期、条款来源和不晚于估值日的条款时点后，才能参与小幅平行利率的一阶情景。估计为金额 × (-修正久期 × 利率变化)，限制绝对利率变化不超过2个百分点、久期不超过100；不含凸性、信用、曲线形状或流动性。此限制只是简化模型的输入范围，不保证精度。

转债仍记录债券/转债资产金额；缺债券/转股条款和含权模型时，利率及含权风险未知，不拿普通债久期代替。其他资产和未知敞口未估计的金额单列，不把未估计当零损失。没有合格久期时情景金额变化为 null，不输出虚假的0。

## 可交互与另存

HTML 可按类型筛选、搜索证券/发行人/行业，并按金额或权重升降排序。筛选只改变显示，不重新归一化权重。情景必须从已声明参数中选择，切换不修改资产金额或原始结果。

“另存所选情景输入”下载可重跑的 JSON，包含选择的情景、方法版本和父输入摘要；“另存所选情景结果”下载该明确情景的参数、局部估计及来源绑定。使用新目录重跑，例如：

```sh
python -m portfolio_engine account-exposure --input scenario-input-rate_up_100bp.json --out reports/rate-up-new
```

此命令生成新报告和清单，不修改历史冻结输入/结果。下载文件是否相同或来自原始结果仍需通过摘要及新报告清单核对。

## 样本与实际验证

[教学输入](../examples/account-exposure-demo.json)的账户金额100000，已知92000、未知8000；账户可用现金10000、冻结5000，另有基金间接现金4000。同证券股票敞口35000、普通债28000、转债10000。上移100基点仅覆盖有教学久期的28000普通债，局部估计 -1120；剩余72000未估计，不能把它称为整个组合损失。制造行业仅为有独立来源的教学股票映射；债券/转债行业缺项保留。

[有限真实身份输入](../examples/account-exposure-limited-real.json)沿用此前已取得的两只基金身份、各42个净值观察的日期范围、采集时间和归档摘要，不附真实净值数值或原始响应。这里每只50000是教学金额，绝非真实账户。没有基金持仓披露，所以底层100%未知；没有可估计利率情景。原净值因完整分红/拆分声明缺失未通过准备，不冒充真实总回报或 M2 验证。

验收包括金额守恒、冻结现金不重复、共享证券两条真实路径、不允许派生行重复导入、循环/缺映射保留未知、发行人/行业证据、日期/币种拒绝、缺条款/转债不强算及另存重跑。真实 Chrome 浏览器验证筛选、身份搜索、数字排序、情景选择、两类下载和下载输入重跑；原 HTML 摘要保持不变。真实账户与证券原件、FX、多币种、复杂冻结/结算、完整债券条款、转债定价及全组合风险尚未实现。
