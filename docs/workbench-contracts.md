# 工作台与引擎的职责和兼容契约（待审）

research-workbench 负责资料整理和研究报告；本引擎负责显式输入下的配置、路径模拟与可核对账本。此次未修改工作台，也未删除其现有功能。

| 能力 | 工作台已有口径 | 引擎与迁移判断 |
|---|---|---|
| 配置 | 下限、常数相关及调用方收缩参数 | 引擎自动 Ledoit–Wolf 常数方差目标；需要转换，不能称等价 |
| 风险 | 经验尾部按向上取整样本计量 | 引擎分数尾部 ES；全套风险报告不等价 |
| 再平衡 | 最低佣金、分资产费率、价差、滑点、日历和成本反事实 | 引擎线性费用；没有完整迁移这些制度 |
| 现金流 | 实际流入前后估值、完整性声明、金额单位、常规现金流 XIRR | 引擎收益路径模拟与根选择不同；不替代实际账户复核 |
| 历史持有路径 | 零费用、无现金流买入持有 | 此次提供限定输入的同口径兼容示例 |

## 首个稳定桥接

输入版本 `workbench-buy-hold-input-v1`，输出版本 `workbench-buy-hold-result-v1`，方法版本 `buy-hold-zero-fee-v1`。示例输入必须显式声明零费用、空外部现金流、基础金额单位、买入持有模式和总回报指数；以首个价格作为起点，初始市值作为权重。

来源以及观察、发布、采集、可得日期声明保留，但不认证历史可得性或源数据真实性。日期排序、拒绝重复和未来日期；不同资产日期不一致时拒绝兼容，不自动补齐。缺数据、费用、现金流、未知字段或其他模式返回明确的不等价/不支持状态。输出目录内保留原输入、参考结果、账本和完整性清单。

仅对照总收益、财富路径、最大回撤和资产贡献。原工作台最大回撤是负百分数，引擎原生损失为正小数，兼容结果显式换算；贡献以百分点表示。未迁移峰谷并列日期规则、相关性、滚动窗口、尾部、情景或文字报告。局部对照成功不能用于宣称工作台全面替代。

```sh
python -m portfolio_engine workbench-buy-hold --input examples/workbench-buy-hold.json --reference examples/workbench-buy-hold-reference.json --out reports/workbench-comparison
python -m portfolio_engine verify reports/workbench-comparison
```

教学输入的财富路径为 1、0.90、0.98、1.10，总收益 10%，兼容最大回撤 -10%，两资产贡献 6 和 4 个百分点。参考结果由只读工作台 `portfolio_stress.py` 中的 `portfolio_path` 计算生成，同输入全部数值差为零。固定来源 Git 提交 `051846168d7590991c75afc001abb97a89b1d3ed`；文件 SHA256 为 `5500bc821d3c166a6aafd478c03b835c7d6dd6636a28ecfb30399a1a914c74c9`。参考文件还记录函数摘要与输入摘要，比较时先检查输入绑定。


后续现金/TWR/XIRR 与现金需求的可选接入见 [有界现金联调契约](workbench-cashflow-integration.md)。观察值复核和未来压力账本保持不同模型。
