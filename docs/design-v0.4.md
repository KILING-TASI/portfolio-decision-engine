# 组合决策引擎设计方案 v0.4

日期：2026-10-09。状态：设计规范，待实现与数据验证。

本版合并 v0.2 与 v0.3 的功能目标，修正公式、统计解释和交易约束。原稿未提供可复现数据的实测数值不作为证据沿用。

## 1. 范围与架构

面向组合层研究：ETF、场外基金、股债金与海外资产；股票组合需要额外的公司行动和成交规则适配。不提供个股推荐或自动交易。

```text
数据快照与交易规则 → 账户账本与组合回测 → M1 候选配置
                                         ↓
                                    M2 回撤预算
                                         ↓
                              M4 迁移 + M5 压力检验
                                         ↓
                              M3/M6 归因 + M7 风险
                                         ↓
                               统一决策卡片与复盘
```

所有模块共享资产标识、估值口径、成本与账本。优化库的收益数组不能替代真实账户账本。

## 2. 数据与回测底座

### 2.1 数据契约

每条序列记录：资产标识、币种、时区、交易场所、日期、来源、获取时间、复权或总回报类型、原始文件哈希、缺失标志、代理标志。财务与成分数据必须保留实际披露时间。

- 研究收益优先使用经核验的总回报序列；前复权不自动等于严格总回报，须验证现金分红、再投资和公司行动处理。
- 实际成交使用当时可交易的原始价格，分红和份额变化进入账本，避免与复权价格重复计入。
- QDII 的场内价格、净值和估值日期分别保存。异步估值只能给近似溢价并标明时点；净值用于资产表现分析，实盘成本与回测成交使用场内价格。
- 清盘、退市及历史成分缺失必须显式披露；不能仅靠接口存在就声称解决幸存者偏差。
- 日历按交易场所维护。周末调休上班不等于交易所开市；跨市场假期、汇率和滞后净值单独处理。
- 新品种代理研究须另列结果、映射和误差，不能冒充该品种自身历史。
- 停牌的账户估值可以沿用最后价格并标记陈旧；统计估计不能把陈旧价格产生的零收益当成可交易的独立观测。禁止静默删掉不利期间。

### 2.2 账本与现金流

账本包含现金、份额、应收应付、成交、费用、分红、申赎待确认状态。外部现金流与内部交易分开记录。

TWR 使用现金流前后估值切分子期间并复利链接；只有日终估值时，披露现金流发生顺序或近似方法。MWR 使用有日期的 XIRR；无解或多解报告状态。含现金流账户的策略 CAGR 来自 TWR 单位净值，不能用期末资产除期初资产替代。

### 2.3 成交、费用与再平衡

费用按资产、方向、生效日期配置：佣金与最低费、税费、买卖价差、成交额参与率及冲击、场外申赎与持有期阶梯费用。税率和交易制度从权威规则核验后版本化，不写死为永恒默认值。

根据品种处理结算、当日回转、涨跌幅、停牌、最小交易单位及资金可用时间。ETF 的交易制度并不全部相同；场外基金确认时间按基金合同配置，不能统一视为 T+1。

收盘信号在之后可成交时点执行。不可成交订单记录未成交、部分成交或延后及原因，不使用理想价补成交。

提供日历与阈值再平衡。相对偏离为 `abs(w_i / target_i - 1)`；目标为零时改用绝对偏离。并列比较净收益、换手、成本、偏离程度。基准使用同样现金流与适用的成本、成交假设。

## 3. M1 配置求解器

### 3.1 候选与约束

默认不估计预期收益来寻找最大收益组合。并列输出等权、最小方差、ERC 与最大分散度；BL 仅在提供观点时启用。约束导致等权不可行时，标明并提供受约束的基准替代，不能称为纯等权。

约束包括资产和类别上下限、现金缓冲、禁卖空、换手及集中度。先验证可行性；例如三只资产的下限 5%、上限 40% 可行，但两只资产同样上限无法满仓。

### 3.2 严格公式

令 `Σ` 为同频协方差、`σ_p = sqrt(w'Σw)`，预算 `sum(w)=1`。

```text
GMV: min w'Σw，满足实际配置约束。
无约束且 Σ 可逆时：w = Σ⁻¹1 / (1'Σ⁻¹1)。

绝对波动贡献：RC_abs_i = w_i(Σw)_i / σ_p
相对风险贡献：RC_share_i = w_i(Σw)_i / (w'Σw)
sum(RC_abs) = σ_p；sum(RC_share) = 1。

ERC: RC_share_i = 1/n。
受约束时可能无法严格等贡献，须报告残差与绑定约束。

最大分散度：max DR = (w'σ) / σ_p。
长仓且 σ_p>0 时 DR≥1，但一般不存在 √n 的统一上界。
对角协方差且允许逆波动权重时，最优 DR=√n。
```

零方差组合的风险贡献和 DR 未定义，不能除零或强行归一化。

BL：`Π=δΣw_mkt`，`M=[(τΣ)⁻¹+P'Ω⁻¹P]⁻¹`，后验均值为 `M[(τΣ)⁻¹Π+P'Ω⁻¹Q]`。`M` 是后验均值的不确定性；在相应独立误差模型下预测收益协方差为 `Σ+M`，二者须区分。实现使用线性求解，不直接求逆。观点、期限、单位、来源、Ω、τ 和市场权重全部披露；无观点时不宣称获得新增预测信息。

### 3.3 协方差

`Σ_hat = δF + (1-δ)S`，`δ∈[0,1]`。

默认可采用成熟库的 Ledoit–Wolf constant-variance 实现，`F=trace(S)/n × I`；constant-correlation 作为独立敏感性版本。两种目标的收缩估计不能混用。原补丁简化的 π/ρ 公式取消，采用经过来源核验的实现。

报告目标类型、收缩强度、样本长度、窗口、年化因子、收缩前后条件数、特征值及实现版本。250/500 日窗口作敏感性分析。`n/T>0.1`、`δ>0.5` 与条件数阈值属于提示规则，不是统计可靠性的定理。高相关资产先提示冗余，是否移除须保留记录。

## 4. M2 回撤预算器

### 4.1 定义与口径

采用正值损失口径：单位净值 `N_t`，`D_t=1-N_t/max_{s≤t}N_s`，`MDD=max(D_t)`。净值起点 1 纳入历史高点。风险预算 `b≥0`；p95 指 MDD 分布的 95% 分位。

每个预算必须指定未来模拟期限 H、训练样本、成本、再平衡、抽样方式。一个期限的 p95 不能搬到另一个期限。

“模型模拟的 p95 不超过预算”不保证未来最大亏损；p95 不是理论下界或上界，自举也不能产生历史中未包含的新风险。历史最大回撤不能证明未来损失边界。

### 4.2 流程

1. 校验数据覆盖、代理与制度断点。A 股历史情景包默认包含 2015 与 2018；缺失时阻止输出“通过历史覆盖校验”的预算结论，但可给明确降级的探索性研究。该规则不直接套用于其他市场。
2. 用训练集生成 M1 候选及约束内候选；记录生成方式和数量。若扫描预期收益，必须说明 μ 来源。
3. 历史回测每个候选；随后对完整多资产收益向量按同一索引联合重采样，保留横截面相关性。
4. 平稳自举：起点均匀抽样；以概率 `1/L` 重启，否则顺延并循环回绕。每条路径长度按 H 定义，不必等于样本长度。
5. 对每条路径重新模拟权重漂移、再平衡及费用。不是先把原组合收益固定下来再打乱，否则改变了策略含义。
6. 报告 MDD p95/p99、条件蒙特卡洛误差、块长敏感性、预算超限概率。p95 本身已经是路径风险分位，误差另列。
7. 筛选 `q95≤b` 的候选，并单列 `q95` 误差区间上端是否超过 b。严格模式可要求上端也不超过 b，但必须披露模式。
8. 以预先指定的训练评分选候选，再用 walk-forward 样本外检验。不能选完后用同一模拟样本声称独立验证。
9. 无可行候选返回 infeasible、最保守候选和超出量，不放宽预算。

场内溢价、流动性与成交限制无法仅从收益重采样完整恢复；未联动建模时标注模拟为收益路径近似，交由 M5 补充。

### 4.3 参数、误差与收敛

起步 `B=2000`，`L∈{10,20,40,60}`，固定并记录随机种子。候选使用共同路径降低比较噪声，独立种子批次用于检查稳定性。

分位数蒙特卡洛标准误近似 `sqrt(p(1-p)/B)/f(q_p)`；尾部密度不稳时用次序统计量区间或独立批次估计并说明方法。这个误差仅描述给定样本、模型下有限 B 的误差，不包括样本不确定性和模型错误。

预先设置容差、最大 B 与批次稳定判据。例如 p95 误差区间半宽目标 1 个百分点属于工程设置，不能承诺一定达到。未达到则 unconverged。块长结果差超过 5 个百分点时并列展示并降级。`T/L` 只近似表示块数量，不是通用有效独立样本量。

### 4.4 输出

同时报告历史 MDD、模拟 p95/p99、H、B、L、误差方法、成本、换手、持有 1/3/5 年的收益分位和亏损概率。模拟与历史滚动持有期分开；重叠窗口的观测数不能当作独立样本数。

“回撤—收益前沿”标为候选集中的经验前沿，不宣称全局最优。长期分布样本不足须降级。

## 5. M3 持仓归因

### 5.1 Brinson–Fachler

```text
配置：Σ_i (w_p,i-w_b,i)(R_b,i-R_b)
选择：Σ_i w_b,i(R_p,i-R_b,i)
交互：Σ_i (w_p,i-w_b,i)(R_p,i-R_b,i)
```

使用期初权重、统一行业分类及版本；配置+选择+交互与单期超额对账。跨资产组合采用相容的分段基准，不能对股债金直接套用缺少对应分段的沪深300。多期采用 Cariño 或 Frongello，并验证复合收益对账。现金、费用、分类缺口及无法归属项单列。

### 5.2 因子归因

超额收益回归含截距，使用 HAC/Newey–West 误差；报告双侧置信区间、p 值、R²、窗口和带宽。`abs(t)>2` 只是粗略筛查，不能证明 alpha 或择时能力真实存在。

市场、市值、价值、动量、波动、流动性因子必须定义样本池、滞后披露、分组、加权、再平衡和可成交规则。六个简化多空因子不能自动称为标准 Fama–French 因子。因子构造本身也需要幸存者偏差与成本检验。

报告 VIF 和相关矩阵。高 VIF 提示系数不稳，并列删减/替代模型敏感性；它不自动使标准误在数学上无效。正交化改变系数解释与顺序依赖，必须披露。风格漂移只作诊断，不能据一次回归强制建议更换策略。

## 6. M4 迁移规划

以金额和份额建模，避免新增资金导致的权重稀释错误。

令当前金额为 x，新增资金 F，买入 b、卖出 s、交易成本 C(b,s)，最终现金 c：

```text
x'_i = x_i + b_i - s_i
c = c0 + F + Σs_i - Σb_i - C(b,s) ≥ 0
V' = Σx'_i + c
目标偏离金额：|x'_i - target_i × V'|

min C(b,s) + λ Σ|x'_i - target_i × V'|
b_i,s_i ≥0；s_i ≤可售金额；锁定品种 s_i=0。
```

成本和偏离项统一为金额，λ 为无量纲参数；其展示网格在统一单位后校准。线性成本可转线性规划，最低费、整数份额及非线性冲击需另行求解或近似并披露。实现须避免同时买卖同一资产。

只买不卖设置 s=0；锁定是不能卖出，不是锁死原权重。现金来源包括卖出所得；原补丁“买入金额≤新增资金”错误约束取消。

输出只买不卖、最小调仓、一步到位三方案的金额、份额、费用、风险变化和目标残差；整数成交与净值确认后重新校验。

临界持有期 `H*=C/(Δα×V)` 仅是忽略复利等因素的一阶收益情景近似。无可信 μ 时不输出虚构 Δα；Δα≤0 时无有限的正收益回本期。风险降低具有独立价值，不能因预期收益不增加就判定“不值得调”。

## 7. M5 压力与情景

历史回放单列 2015、2018、2020、2022，并按市场适配。历史估计允许使用情景前训练权重，或明确标注“当前固定配置反事实回放”；不能混为当时可实现的策略。

输出 MDD、最差月、成本和恢复时间；恢复窗口延长到高点被重新达到，若截至观察日仍未恢复则标注右删失，不编造月份。

合成利率情景使用 `ΔP/P≈-D_modΔy+0.5 Convexity(Δy)^2`，明确久期、凸性、信用与汇率假设；大幅冲击只作近似。通胀情景回归不是因果预测，报告估计区间和适用范围。

未经历情景的资产标记缺失；代理版本另列。压力情景不与概率分位互相替代。

## 8. M6 交易归因

构造 A 实际交易、B 期初持有、C 预先定义目标与再平衡规则三条路径。使用相同起始资产、外部现金流、估值与成交条件，分别计入各路径实际发生的成本。

报告 A−B、A−C、C−B 的净值和期末财富差；它们反映路径差异，不自动证明择时能力或均值回复。机械再平衡也可能跑输买入持有。

原逐笔 `Δw×期末超额收益` 只作近似解释，不能直接当可加总的精确交易贡献。精确分解需账户级现金流、份额与多期链接；展示残差，与总差额对账。择时与换仓划分先定义，不能重复归属。

无完整交易记录和足够估值时拒绝可靠交易分解；只靠期末持仓也无法可靠恢复 A 路径。全体已平仓资产纳入，毛贡献、费用、净贡献并列。结论不预设 ETF 应多调或场外基金必应少调。

## 9. M7 风险度量

采用损失 `L=-r`：`VaR_α=q_α(L)`，`ES_α=(1/(1-α))∫_α^1 q_u(L)du`。有离散质量点时用分位积分或边界加权，而非简单条件均值。报告期限、频率、尾部观测数；尾部少于 30 个时降级并列 ES90。

Sharpe 使用同频平均超额收益除标准差，年化方法显式；自相关下不能机械依赖 IID 标准误，默认分块自举区间。Ljung–Box 未拒绝也不证明 IID。Sortino 的最低可接受收益、Calmar 的窗口和分母均须定义。

Cornish–Fisher 只作可选对照：检验声明 z 区间内分位映射单调性与参数适用域，不合格则不输出；某一组偏度峰度不能脱离检验区间预先认定失效。历史法、Student-t 也有模型和样本局限。

```text
N_eff_weight = 1 / Σw_i²，适用于归一化非负持仓权重。
N_eff_RC = 1 / ΣRC_share_i²，仅在 RC_share_i≥0 且和为1时作有效风险数解释。
```

对冲可产生负风险贡献；此时报告正负贡献、风险抵消和集中度，暂停“有效资产数”解释。权重有效数不度量相关性；等权的十只高度相关基金仍有权重有效数 10，须结合相关性、分散比及因子集中判断。

危机相关性可能上升但不必趋于 1；指定危机窗口与样本数。矩阵需半正定且满足求解器要求；修正方式、幅度和原因留档。

## 11. 样本外评估与验收

训练、参数选择与测试严格分离，walk-forward；重叠持有期评估按期限留出边界隔离。报告尝试参数组数，多重选择需采用适当的 Deflated Sharpe/Reality Check 等检验并注明适用假设。每次选择都保存候选与失败结果。

收益、风险、稳定性和成本均与公平基准比较，未产生样本外价值则明确报告。未来预算突破记录频次、期限和不确定性；重叠预测不能视为独立命中试验。

| 验收 | 期望 |
|---|---|
| 风险贡献 | sum(RC_abs)=σ_p；sum(RC_share)=1；零方差明确未定义 |
| ERC 对称例 | 等方差等相关、可行长仓约束得到等权 |
| 最大分散 | 对角阵且约束允许时最优 DR=√n；负相关例可超过 √n |
| 收缩 | δ∈[0,1]；目标与官方实现一致；S=F 时不要求唯一 δ |
| 联合自举 | 所有资产共享行索引；路径长度符合 H；固定种子可重现 |
| MDD 符号 | 单调上升路径为0；先跌20%再恢复路径 MDD=0.2 |
| 误差 | 增大 B 检查蒙特卡洛区间稳定，不能视为增加历史信息 |
| 迁移 | 新增资金、卖出所得、费用与现金守恒；锁定资产仍可稀释 |
| 负风险贡献 | 不输出有误导含义的有效风险资产数 |
| 现金流 | 无收益仅入金时 TWR=0；XIRR 异常状态明确 |
| 归因 | 单期与多期对账；成本单列；残差可追溯 |
| 恢复时间 | 未恢复标记右删失 |
| 公平基准 | 一致的成本规则、外部现金流和成交条件 |

上述为待实现验收规范，不代表测试已运行。

## 12. 交付阶段

| 阶段 | 内容 | 交付门槛 |
|---|---|---|
| P0 | 数据快照、账本、成本、现金流、等权/GMV/ERC | 守恒、复权与成交验收通过 |
| P1 | M2 联合自举、期限、误差、预算拒绝、经验前沿 | 收敛与样本外评估可复现 |
| P2 | M7、M4、M5 | 风险口径、迁移可执行性、删失状态正确 |
| P3 | M3 Brinson 与多期链接 | 复合收益对账 |
| P4 | 因子与风格漂移 | 时点数据、构造与回归可追溯 |
| P5 | M6 完整交易归因 | 三路径公平性和贡献对账 |

M6 简化三路径比较可在账本完备后提前。多账户汇总、成本敏感性、滚动相关可视化为后续扩展。

## 13. 已知边界

历史重采样依赖样本代表性与近似平稳性；制度断点和跨市场异步价格会削弱结论。预期收益难以可靠估计；长期概率并非保证；数据接口不能自动提供无偏历史资产池。此设计的价值在透明比较与复盘，不能消除投资风险。

公式、实现来源与组件边界见 [开源组件](open-source-components.md)。
